KDS Lab Desk

A simple reporting program for one lab PC. It works fully without internet, saves itself to the cloud whenever internet is available, and turns a report into a print or a WhatsApp message in one click.

His whole day, in three screens
1 · Register

New patient नया मरीज़

Name, age, sex, phone, doctor. Tick the tests. Bill prints if needed.

2 · Enter results

Type the numbers

Only the measured values. Ranges, units, calculations and H/L flags are filled in for him.

3 · Finish

Print or WhatsApp

One button prints the report on his letterhead. One button sends it to the patient's WhatsApp.

No folders, no file names, no copying an old Word file. Every old report is searchable by name, phone or date.

How the sync works

Lab PC (main copy)

All patients and reports are kept on the PC. Everything works with the internet off, the whole day if needed.

→when internet is on

Secure cloud (India region)

Each new or changed report is copied up within a minute. Encrypted. Keeps a full history.

→read only

Phone, patient, doctor

He checks the day on his phone. Patients open their PDF from a link. Doctors can see reports they referred.

  • Nothing waits for the internet. Saving, printing and searching always happen on the PC. Changes queue up and upload by themselves when the connection returns.
  • One place makes reports. Only the lab PC creates and edits reports, so two copies can never disagree. The phone is for viewing and sharing.
  • Three backups without thinking: the cloud copy, an automatic nightly copy on the PC, and a weekly reminder to plug in a pen drive (one click).
  • New PC or hard-disk failure: install, sign in, and everything comes back from the cloud.

Built from what we found in his 1,441 old reports

What the software fixes

Found: 131 reports print MCH “27 – 321”; ranges differ between files

One master list of tests, units and ranges (male, female, child). Set once, used everywhere. Only he can change it.

Found: MCV/MCH/MCHC wrong in 150 of 338 CBCs

Calculated values are worked out from Hb, PCV and RBC. He can still enter analyzer values and gets a warning if they don't match.

Found: 29 sets of identical results under different names

Every report starts with empty boxes. Saving is paused if the values match another patient's report.

Found: no abnormal value ever marked

Values outside the range print bold with H or L. Very dangerous values (e.g. Hb below 7) show a red warning on screen.

Found: “MR. … / FEMALE” on 20 reports

Choosing Mr / Mrs / Miss fills in the sex, and the right sex-specific ranges follow.

Found: Thyrocare reports kept as edited Word files

Sent-out tests are logged as “sent to Thyrocare” and their original PDF is attached as received. The software never produces another lab's report.

Every approved report is locked. A correction makes a new version and keeps the old one, with the time it was changed.

Less work every day

What runs on its own

  • Typing a phone number lists every family member who uses it. He taps the right person (or adds a new one), and details fill in from that person's last visit. Their previous results show beside today's. A warning appears if the age or sex doesn't fit that person.
  • A patient without a phone can still be found by name and village.
  • Test panels (CBC, LFT, KFT, Lipid, Widal, MP, Dengue, Sugar, Urine, Serology…) set up from his current report formats.
  • Optional: CBC values read straight from the haematology analyzer by USB cable, if the model supports it.
  • Bill and receipt, today's cash total, pending payments.
  • Monthly list of patients sent by each doctor.
  • Pending list: tests registered but not yet reported, sent-out samples not yet back.
  • Screens in English or Hindi; reports print in English.
  • Updates install by themselves overnight. Nothing for him to configure.
  • His old Word reports are imported once, so patient history from past years is searchable from day one.

Technical choices

PartChoiceWhy
Desktop appTauri (Windows installer), React screensSmall, fast on an old PC, desktop icon, auto-update built in.
Local dataSQLite database, one fileVery reliable, no server to run, easy to back up.
Patient identityPatient ID per person; phone is a shared contact field (many patients → one number)Families share one phone; the number groups a household and never identifies a single patient.
ReportsPDF generated from one HTML templateIdentical layout on screen, printer and WhatsApp. A4 or Letter, letterhead or pre-printed paper.
SyncOutbox queue → Supabase (Postgres + file storage, Mumbai region)Single writer (the PC), so no conflicts; retries until it succeeds.
Report linksShort link + PIN, signed and expiringPatients open their report without an account; strangers can't guess links.
PrivacyEncrypted at rest and in transit; patient consent line on the billHealth data, covered by India's DPDP Act.

Running cost: cloud starts on a free tier and stays around a few hundred rupees a month at this lab's volume; a domain for short links is about ₹1,000 a year. WhatsApp Level C adds Meta's per-message charge.

Roadmap

Delivery in four steps

Week 1–2

Offline reporting

Register, enter results, master test list, checks and flags, print on his letterhead, search. He starts using it next to Word.

Week 3

WhatsApp + backups

WhatsApp Level A, bills, nightly and pen-drive backups, import of old reports.

Week 4–5

Cloud sync

Sync, phone view, report links with PIN, QR verification, WhatsApp Level B. Word stops being needed.

Later

Extras

Analyzer connection, WhatsApp Level C, doctor view.
